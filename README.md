- RBAC/ACL e permessi granulari

- Job queue con retry/backoff
- OpenTelemetry e osservabilità

**AI automation (assistente operativo)**

## 🏗️ Architettura

Il sito segue principi di design chiari:

- **Moduli separati**: API → Servizi → Data access
- **Permessi first**: RBAC/ACL nel design, non come afterthought
- **Stati osservabili**: tutto è tracciato con audit log
- **Retry/backoff**: gestione affidabile di dipendenze esterne
- **Osservabilità**: debug ripetibile con log strutturati
